# Contributing

Bug reports, ideas and pull requests are welcome.

- **Bugs and feature requests:** open an [issue](../../issues/new) with a short summary, steps to reproduce, what you expected and what happened (logs help).
- **Pull requests:** fork the repo, branch from `main`, keep changes focused, update the README if behaviour changes, and make sure `scripts/lint` (ruff) passes.
- **Development:** `.devcontainer.json` starts a VS Code dev container with a standalone Home Assistant instance configured via [`config/configuration.yaml`](./config/configuration.yaml).

By contributing, you agree that your contributions are licensed under the GNU GPL 3.0 that covers this project.
